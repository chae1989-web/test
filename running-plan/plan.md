- **레이스로 증명된 VDOT: 47.7** (PR 기준: 5K 21:24 / 10K 45:02 / HM 1:38:56 / FM 예측 3:29:13와 정합)
- 참고: 가민 VO2max 추정치는 57(최근 8주 55→57 상승 추세)로 더 높게 나오지만, 이는 실측 레이스로 검증되지 않은 값이므로 **훈련 페이스는 VDOT 47.7 기준으로 설정**한다. VO2max와 실제 레이스 능력 사이의 갭은 곧 이 훈련(NSM sub-threshold + 볼륨)으로 좁혀야 할 대상.
- 목표(10K sub-40 / HM sub-1:30)는 VDOT 약 58 수준이 필요 — 현재(47.7) 대비 큰 도약이므로 **공격적인 스트레치 목표**로 다루고, B레이스(10/18)·중간 타임트라이얼에서 실측 후 재보정한다.

## 훈련 방법론: NSM (Norwegian Singles Method)

- 주당 구조화 워크아웃 **최대 4회 = sub-threshold 세션 3 + 롱런 1**, 나머지는 완전 이지런/휴식
- sub-threshold 세션은 전력질주가 아닌 "컨트롤된 comfortably-hard" — LT(165bpm)보다 분명히 낮게, 반복 가능한 강도
- 인터벌은 **시간 기준**: 3min x 8~10rep / 6min x 4~5rep / 12min x 2~3rep, 반복 간 조깅 리커버리 60초 내외. 단계가 진행될수록 반복시간 증가(3→6→12분), 반복수는 감소
- VO2max/전력 인터벌은 최소화, 레이스 임박 구간에서만 짧게 포함
- 이지런은 진짜 이지(HR 캡)로 철저히 통제 — sub-threshold 세션의 질과 빈도를 지키는 핵심 전제

## 자동 Routine

- **주간**: 매주 일요일 저녁 실행 — 지난주 가민 데이터(피로도/회복) 점검 → 이 표의 현재 단계 규칙에 맞춰 다음 주 워크아웃(최대 4개) 설계 → 위 라이브러리 workout_id로 `schedule_week`/`schedule_workouts` 등록 → 세션에 요약 메시지 전송 → 아래 실행 로그에 한 줄 추가
- **일간**: 매일 아침 실행 — 오늘 예정 워크아웃 확인 → 컨디션(readiness/HRV/수면) 확인 → 저조 시 퀄리티 세션을 이지런으로 교체 → 브리핑 메시지 전송
